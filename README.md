
🌿 The Plant Nook
A simple, clean, and responsive indoor plant shop website.

Built with passion for greenery, this project showcases a curated collection of indoor plants with a focus on minimalist design and user experience.

✨ Features
Minimalist UI: A clean, nature-inspired aesthetic using a soft green color palette.

Plant Gallery: High-quality images of popular indoor plants (Monstera, Snake Plant, etc.).

Product Details: Clear pricing and descriptions for every plant.

Responsive Design: Fully optimized for mobile, tablet, and desktop viewing.

GitHub Pages Hosted: Fast, secure, and always online.

🛠️ Tech Stack
HTML5: Structured the content and product information.

CSS3: Styled the layout using Flexbox/Grid and custom animations.

GitHub Pages: Seamless deployment and hosting.
